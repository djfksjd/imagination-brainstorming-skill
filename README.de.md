> [!TIP]
> Für die meisten Nutzer empfehlen wir
> [Imagination](https://github.com/djfksjd/imagination): Es erzeugt Richtungen,
> wartet auf deine Wahl und übergibt sie an diesen Workshop.

Imagination Brainstorming beginnt **nach der Auswahl einer Richtung**. Vor der
Umsetzung prüft es Ziel, Vorgaben, stärkste Alternative, Alltagsbetrieb und den
mechanismuseigenen Fehler.

```text
Gewählte Idee → Vorgabenprüfung → Belastungstest → entscheidungsreifes Konzept
```

## Beispiel

```text
Nutze $imagination-brainstorming und entwickle diese Option mit erster Nutzung,
laufender Arbeit, eigenem Fehlermodus, Widerlegung und nächster Entscheidung.
```

## Messergebnis

| Kennzahl | Gegenüber starkem Prompt |
|---|---:|
| Präferenz für die Planung | **45–5 (90,0 %)** |
| Umsetzbarkeit | **+1,37** |
| Entscheidungspassung | **+0,95** |
| Kausale Klarheit | **+0,71** |
| Robustheit | **+0,82** |

Das ist ein Modellrichter-Ergebnis aus einem vorregistrierten Blindtest, keine
universelle Garantie.

## Einzelinstallation

```bash
curl -fsSL https://raw.githubusercontent.com/djfksjd/imagination-brainstorming-skill/main/install.sh | bash
```

[Imagination Engine](https://github.com/djfksjd/imagination-engine-skill).
